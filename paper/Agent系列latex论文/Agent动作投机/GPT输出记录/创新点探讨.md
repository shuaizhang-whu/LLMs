论文方案：根据投机候选数量，训练动作预测器
我们提出的核心方法是：
让预测器直接学习“生成的几个候选中，至少一个命中 Actor 最终动作”，并根据允许生成的候选数量，调整预测策略。

一、这个创新具体解决什么问题
假设 Agent 正等待工具返回，我们可以提前预测下一次工具调用。
如果只允许预测一次，应该集中猜最可能的动作；如果允许预测四次，就应该把一部分预测机会分给其他可能动作。
因此，预测器需要学习的不是固定的输出习惯，而是：
给定当前历史和候选数量 \(K\)，怎样分配动作概率，才能让这 \(K\) 次预测尽量覆盖最终动作。
这里的动作必须包含完整工具名和参数。例如：
search(query="Alan Turing birthplace")
仅猜对 search，参数不一致，不算命中。
二、从命中目标推导训练公式
用 \(x\) 表示预测时能看到的历史，\(a^*\) 表示 Actor 随后实际选择的动作。
预测器生成这个动作的概率记为：
\[
q_\theta(a^*\mid x,K).
\]为了简化，下面写成 \(q\)。
一次预测没有命中的概率是 \(1-q\)。如果独立生成 \(K\) 个候选，全部没有命中的概率就是：
\[
(1-q)^K.
\]因此，至少有一个候选命中的概率是：
\[
\boxed{P_{\text{hit}}=1-(1-q)^K}
\]我们直接最大化这个概率。 对训练数据中的每一个真实动作，定义损失：
\[
\boxed{
\mathcal L(\theta)
=
-\frac{1}{N}\sum_{i=1}^{N}
\left[
1-
\left(
1-q_\theta(a_i^*\mid x_i,K_i)
\right)^{K_i}
\right]
}
\]公式的含义就是：训练时直接奖励有限候选中的完整动作命中。
同一个动作概率，在不同 \(K\) 下，对命中的贡献不同。例如 \(q=0.5\)：
- 生成一个候选，命中概率为 \(0.5\)。
- 生成四个候选，命中概率为 \(0.9375\)。
有四次机会时，继续提高这个动作的概率，边际收益已经比较小；模型可以把更多概率分配给其他可能动作。这就是预算影响预测分布的原因。
三、训练具体怎么做
第一步：构造数据。
从固定 Actor 的轨迹中提取：
输入：预测发生时的历史 x
标签：Actor 后来真正生成的完整动作 a*
附加输入：允许预测的候选数量 K
预测器不能看到尚未返回的工具结果。标签使用 Actor 实际动作，不替换成我们认为更正确的动作。
第二步：先做普通微调。
先让小模型学会输出格式正确、参数合理的动作。这个阶段是必要的，因为完全没学会动作格式时，真实动作概率可能极低，后面的训练信号会很弱。
第三步：用上面的命中损失继续训练。
例如从 \(K\in\{1,2,4\}\) 中选择预算，将其加入模型输入：
当前历史：……
候选预算：4
请预测下一次完整工具调用。
训练时不必真的执行四次工具调用。我们通过 teacher forcing，计算标签动作的完整序列概率：
\[
q_\theta(a^*\mid x,K)
=
\prod_{t=1}^{L}
q_\theta(y_t\mid x,K,y_{<t}),
\]其中 \(y_1,\ldots,y_L\) 是规范化动作序列，包含结束标记。然后代入命中损失，反向传播更新小预测器。
这里必须使用完整动作的联合概率，不能用平均 token 概率代替。动作格式也要统一，否则同一个调用的不同字符串表示会分散概率。
第四步：部署到 SA。
运行过程是：
当前历史 + 候选预算 K
          ↓
小预测器独立生成 K 个候选
          ↓
去重，并提前执行允许投机的工具
          ↓
Actor 根据真实信息生成正式动作
          ↓
严格匹配则复用，否则走原执行路径
候选预测不参与修改 Actor 的决策。方法改变的是提前猜测的内容。
四、理论上为什么有可能更好
令 \(p_a\) 表示在当前可见信息下，Actor 最终选择动作 \(a\) 的概率。整体命中目标为：
\[
J_K(q)=\sum_a p_a\left[1-(1-q_a)^K\right].
\]这个式子揭示了两种不同策略：
- 当 \(K=1\) 时，目标是 \(\sum_a p_aq_a\)，最优策略集中预测最可能的动作。
- 当 \(K>1\) 时，反复预测同一个动作的收益会饱和，覆盖其他可能动作开始变得有价值。
我们的训练目标就是把这种预算变化直接写进模型学习过程。
这个推导成立于独立候选采样的设定。它说明方法有合理的优化目标，尚不能证明真实任务中一定加速。尤其完整动作很长时，联合概率可能很小，这是后续需要解决的训练问题。
这篇论文拟主张的创新，可以压缩成一句话：
提出一种面向有限投机预算的动作预测训练方法，以完整动作的至少一次命中概率为直接目标，使小预测器学习随候选数量变化的概率分配策略，在保留 Actor 正式验证的条件下提高投机覆盖效率。

这是一个具体的方法提案；目前能推导的是目标与训练过程，实际增益和新颖性仍需后续确认。

是的，前面的 \(K\) 指候选分支的宽度；目前方案只预测下一步，深度固定为 1。 两个问题分别解释如下。
注释 1
固定预测器、独立采样时，\(K\) 越大，至少命中一次的概率越高。
对于某个最终动作，单次生成它的概率为 \(q\)，则：
\[
P_K=1-(1-q)^K.
\]增加一个候选带来的增量是：
\[
P_{K+1}-P_K=q(1-q)^K.
\]当 \(0<q<1\) 时，这个增量为正，并且越来越小。因此是命中概率提高，但边际收益递减。
不过，需要区分两个问题：
- 增加候选数量：固定预测器，多猜几次，自然更容易命中，但需要更多生成和预执行成本。
- 我们提出的训练方法：在相同的 \(K\) 下，调整预测器的概率分配，争取用同样数量的候选获得更高命中率。
我们要研究的是第二个问题。仅仅证明 \(K=4\) 比 \(K=1\) 命中更多，不构成这个方案的创新。
另外，上式要求独立采样。如果用 greedy 把同一个动作重复生成四次，就没有四次独立机会。命中概率提高也不自动意味着加速，因为候选生成、工具执行和资源竞争都有成本。
我之前“模型可以把更多概率分配给其他动作”的解释也需要补充：是否值得分配，还取决于那些动作被 Actor 最终选择的概率，不能只根据 \(K\) 判断。
注释 2
这里研究的是宽度，不是 DSP 所讨论的规划深度。 前面没有明确区分，是我表述不完整。

\(D\)：深度	一个分支连续向后预测多少步	固定为 1

  └─ 候选动作 C
A、B、C 都是在猜 Actor 的同一个下一步。
而向后预测深度为 3 的一条分支是：
当前历史 → 动作 A₁ → 返回 O₁ → 动作 A₂ → 返回 O₂ → 动作 A₃
这里后续动作依赖前面动作的返回。对这样的动作链，需要考虑的是“能连续匹配多少步”。
令 \(L\) 为连续匹配的前缀长度，则：
\[
\mathbb E[L]
=
\sum_{d=1}^{D}\Pr(L\ge d).
\]进一步，令
\[
r_d=\Pr(\text{第 }d\text{ 步匹配}\mid\text{前 }d-1\text{ 步均匹配}),
\]就有：
\[
\Pr(L\ge d)=\prod_{j=1}^{d}r_j.
\]这说明：宽度增加的是同一步的备选机会；深度增加的是一条路径能提前推进的距离。 后者还需要处理中间 observation、状态有效性和前缀失配后的丢弃。
因此，目前这个方案的准确名称应是：固定单步深度下，面向候选宽度预算的动作预测训练。 它尚未解决动态深度，也不能用前面的单步覆盖公式宣称已经覆盖多步规划。
