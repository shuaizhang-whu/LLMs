# 02 · DSP：动态投机深度，以及“预测准确”与“决策划算”的区别

阅读日期：2026-09-08。论文：**Dynamic Speculative Agent Planning**，简称 DSP。

来源：本地 LaTeX 全部正文，并核对官方 PDF 的关键图表和方法定义；[arXiv v3](https://arxiv.org/abs/2509.01920v3)，2025-09-21，首版 2025-09-02。DSP 早于 Speculative Actions，阅读顺序不代表继承关系。本轮未运行项目代码。

笔记目标：为后续比较和筛选研究问题保留证据，不逐段翻译。下文区分**论文结果、分析判断、待验证假设**；候选问题不等于已确认的新颖贡献。

## 1. 最值得记住的结论

**DSP 学习“当前轨迹适合向前投机多少步”，通过控制深度减少失配后被丢弃的推理。它没有直接学习美元或端到端延迟最优的调度策略。**

| 后续选题需要记住什么 | 判断 |
|---|---|
| 动态 speculation depth 是否空白？ | 不是。DSP 已有上下文相关的在线步长预测。 |
| 能否靠“增加在线学习、回放缓存、偏置调节”构成主要创新？ | 单独不行，这些已包含在 DSP 中。 |
| 最有用的问题线索 | 连续匹配长度是否足以决定经济上最优的投机深度？ |
| 最容易误读的结果 | “冗余成本降低约 60%”不等于比原始 Target 单独运行便宜 60%。 |
| 正确性边界 | 保留 Target 的规划行为，需要匹配前缀及其条件状态一致；取消推理线程不等于回滚真实工具副作用。 |

## 2. 核心机制：沿着一条草稿链并行验证

设 A 是快速 Approximation planner，T 是较慢的 Target planner。快慢可以来自不同模型，也可以来自不同推理方式，例如直接输出动作与多轮 debate。

以旅行规划为示意：A 先提出“选择城市 → 选择交通 → 选择酒店 → 安排餐厅”。这里先把它理解为**规划步骤**，不能直接等同于已经完成购票和订房。

1. 在已确认的状态 `s` 上，小型预测器给出本轮预算 `K`。
2. A 依次生成草稿步骤。每个草稿步骤对应启动一个 T 计算，T 根据该步之前的草稿前缀，产生自己的下一步。
3. 因为 A 快，多个 T 计算可以同时进行。T 不是简单判断“这步看着是否合理”，而是保留原有规划计算。
4. 按依赖顺序接受匹配的前缀。假如第三步不匹配，就采用 T 的第三步，丢弃第三步之后依赖错误草稿的结果，并取消相关未结束线程。
5. 从修正后的状态继续；利用已完成的匹配/失配信息更新步长预测器。

**关键收益**：把多个昂贵 T 步骤重叠起来。**关键浪费**：A 走得过远时，不仅 A 白算，依赖错误前缀的 T 也白算；取消时输入 token 的开销可能已经发生。

预算小会限制并行度，预算大可能放大浪费。DSP 的贡献就是根据当前上下文调节这个预算。

## 3. 它训练了什么？没有训练什么？

预测器是 DistilBERT，输入轨迹文本，输出步长估计。A/T 的大模型策略不是本文在线训练的对象。

论文用价值估计形式学习剩余投机长度：TD 的 `λ-return` 作为目标，实验 `λ=0.95`；`λ=1` 时退化为基于完整回报的在线监督学习。训练与推理异步运行，使用两份预测器权重并同步。

主要配置：AdamW，学习率 `1e-5`，batch 16，replay buffer 2500，每次训练 3 epochs。

成本—延迟控制有两种方式：

- **Expectile regression**：非对称平方误差，较大的 `τ` 倾向于预测更大的步长。
- **Offset**：`K=max(1,预测值+β)`，加偏置使策略更激进。

需要区分：`τ=0.9` **不是**“有 90% 概率安全”，也不是超时概率约束。它改变回归目标的偏向；论文通过实验展示成本与延迟随之变化。

### 一个实现前必须核对的定义问题

建议后续统一使用三个量，避免沿用论文中混杂的 `k`：

- `L`：连续匹配的步骤数。
- `H=L+1`：第一次失配的位置，假设最终遇到失配。
- `K`：调度器实际允许展开的预算。

正文说 episode 在失配时结束，但奖励段落又写成“失配奖励 1，否则奖励 0 并立即结束”，两者冲突。Figure 1 中 A、B 匹配而 C 失配，标签为 `3、2、1`，看起来计入了失配步，对应 H 而非 L。

**判断**：这是需要代码确认的定义/表述问题；不能默默改一下奖励，就声称已经精确还原算法。发现写作错误本身也不是研究创新。

## 4. “Lossless”在什么条件下成立？

可用归纳思路理解：如果提交前缀与串行 T 一致，且下一步 T 看到的条件输入、环境状态也一致，那么提交它自己的下一步，就可以继续保持一致。草稿错误的后代必须作废。

这个逻辑依赖至少三件事：

1. **匹配标准足够强**：动作名相同不够，参数、影响后续行为的状态也需要一致。
2. **T 的条件上下文正确**：若保留了 A 的不同 reasoning，即使动作相同，下一步 T 的输入也可能不同。需要看历史具体保存什么。
3. **错误分支没有污染正式环境**：已经发生的外部写操作，不会因为取消 LLM 线程而自动撤销。

随机 T 还要区分分布保持和固定一次运行的轨迹完全相同；两者不能混称。

**证据边界**：DSP 提供规划层面的机制解释，但不能据此推出任意有副作用工具环境都严格 lossless。论文主结果也没有用任务成功率和环境状态等价实验完整验证这一推广。后续 PASTE、AOSpec、SMC 是核查这一问题的重点。

## 5. 实验究竟支持了什么？

### 设置和 baseline

| 项目 | 内容 |
|---|---|
| 数据 | OpenAGI 312 个任务；TravelPlanner 180 个任务 |
| 模型 | GPT-4.1-mini；DeepSeek-chat / DeepSeek-reasoner |
| 规划方式 | A：Direct 或 CoT；T：ReAct 或两智能体、两轮 MAD |
| 主 baseline | 固定 `K∈{2,4,6}`，不是 Speculative Actions |
| 消融/比较 | 不同 τ、offset；TD vs SFT；非上下文的搜索启发式；在线 warmup；token 成本分解 |
| 主指标 | 延迟、prompt/generation tokens、估算费用、平均峰值并发、平均步长 |

论文按其当时列出的 API 单价计算费用；这些不是当前价格。也不能仅因 benchmark 名称包含工具，就推断实验已测量完整外部工具执行、隔离和回滚开销。

### 代表性结果

以下 T 和 Cost 均以**同设置的固定 K=2 为 1**，越低越好；数值来自论文主表。

| 设置 | 策略 | T | Cost | 可以得出的结论 |
|---|---|---:|---:|---|
| OpenAGI，GPT，Direct-ReAct | 固定 K=6 | 0.90 | 1.92 | 更快，但更贵 |
| 同上 | DSP，offset=2 | 0.90 | 1.25 | 表中延迟相当，费用约少 34.9% |
| 同上 | DSP，τ=0.5 | 1.01 | 0.88 | 比 K=2 便宜，但略慢 |
| OpenAGI，GPT，CoT-MAD | 固定 K=6 | 0.81 | 1.77 | 高深度基准 |
| 同上 | DSP，offset=2 | 0.80 | 1.27 | 此设置得到更好的成本—延迟组合 |
| TravelPlanner，Direct-ReAct | 固定 K=6 | 0.87 | 2.91 | 表中较激进的速度端点 |
| 同上 | DSP，τ=0.99 | 0.92 | 1.48 | 省费用，同时牺牲部分速度 |

**支持的结论**：动态预算在多个设置中减少固定大深度的浪费，提供了有用的成本—延迟选择。

**不能直接推出**：DSP 严格支配所有固定策略。TravelPlanner 就有明确的速度换成本情形；固定深度只测了 2、4、6，也不是穷尽所有静态选择。相同的两位小数延迟不等于统计等价。

### 两个必须保留的指标口径

**第一，冗余费用的基准是 A+T。** 论文将 A 与 T 串行规划的费用之和作为最低基准，将超出部分称为冗余。它没有把 A 的固有费用都算作相对于原始 T 的额外负担。

例如 OpenAGI GPT Direct-ReAct 中，固定 K=6 的 `ΔCost=176.25%`，DSP offset=2 为 `69.36%`，对应冗余指标减少约 `1−69.36/176.25=60.65%`。这与上表的**总费用减少约 34.9%**是不同口径，更不是比 T-only 便宜 60%。后续复现必须增加 T-only 的端到端参照。

**第二，平均步长不是实测平均并发。** 论文用平均 K 作为持续并发的代理。真正的时间平均并发应由调用起止时间计算；多轮 MAD、调用时长差异和空闲都会影响两者关系，不能直接将其当作 GPU 利用率下降。

### 消融的证据强度

- **TD vs SFT**：表中 TD 通常更快，费用接近或更低；但要区分 TD 学习本身的好处，与输出步长更激进的好处。后续应给 SFT 同样的 offset/τ 调参预算，再比整条曲线。
- **在线适应**：论文报告 GPT 约 3–5 个任务、DeepSeek 约 8–10 个任务 warmup。这不等于已证明任务分布突变后的适应能力，也不等于在线训练免费。
- **非上下文启发式**：比较说明上下文可能有帮助，但没有排除简单的分桶统计、滑动匹配率控制等强基线。

**复核备注**：除奖励表述冲突外，成本分解表 `τ=0.5` 一行的四项 token 之和为 21561.1，而 Total Token 写成 21443.4。暂不引用该行做精确收益承诺；复现时依据日志重算，不凭猜测修正表格。

## 6. 与 Speculative Actions 放在同一张图中

| 维度 | Speculative Actions | DSP |
|---|---|---|
| 主要抽象 | 预测当前 API 返回，预启动后续真实调用 | 快 A 展开规划草稿，慢 T 对各步并行生成并匹配 |
| 主要控制变量 | 候选宽度、置信度；也讨论深度扩展 | 依据上下文在线预测投机深度 |
| 投机失误损失 | 未用上的预执行、额外推测开销 | A 草稿及依赖错误前缀的 T 计算浪费 |
| 提交依据 | 正式调用与缓存键匹配，仍需结果/状态条件 | 顺序接受匹配前缀，在失配处采用 T 结果 |
| 成本控制 | 已有成本/置信度相关分析 | 长度价值估计，加 expectile 或 offset 调节 |
| 共同未充分解决的推广 | 外部状态、副作用及资源竞争下的保证 | 同左；动态长度预测不自动解决它们 |

不要把两者差异简化成“第一篇单步，DSP 多步”，也不能因为 DSP 能动态选 K 就认为投机调度已经彻底解决。

## 7. 留给后续选题的三张问题卡

### R1：匹配长度目标与成本—延迟目标是否错位？

**依据**：DSP 主要学习轨迹还能匹配多长，再用 τ/offset 调节偏向；训练目标没有直接纳入每步费用、调用时长和取消成本。

**可检验假设**：在匹配规律相近、但上下文长度或服务延迟不同的状态中，长度预测相同仍可能需要不同预算。正确长度不一定对应最小 `E[延迟+η×费用]`。

**最小实验**：固定模型和轨迹匹配结果，仅改变计时/费用条件；比较 DSP 与经过充分调参的固定 K、DSP+offset、简单边际收益阈值。先做离线调度回放，出现稳定差距才进入真实服务验证。

**放弃条件**：简单 offset 或阈值已基本消除差距；收益只出现在人为极端延迟；或后续论文已解决同一问题。

**新颖性待查**：SA 的成本分析、PASTE/SPORK/AOSpec 的调度目标。只有“把 latency 加进 reward”不够。实现难度先低后中，无需先训练大模型。

### R2：预算截止会不会让在线长度标签失真？

**依据**：若预算 K 用尽时仍未失配，只知道 `H>K`，不等于已观察到真实 H；如果错误地当成终止标签，保守策略可能不断收集偏短标签。

**注意**：这是条件性风险，**尚未证明 DSP 实现存在该问题**。Figure 1 的标签似乎跨过了一个预算窗口；正确的跨窗口拼接或 TD bootstrap 可能已经处理它。

**最小实验**：以后先查 episode 终止标记、标签拼接和 bootstrap；再用已知失配位置的短轨迹改变 K，检查估计是否系统性偏移。无需调用大量 LLM。

**放弃条件**：实现已正确处理，或偏差不影响实际决策。处理删失数据本身是已有统计思想，不能直接包装成新方法。

**后续核查**：DSP 代码及其他在线投机控制方法。实现难度低，适合先做问题诊断。

### R3：步长预测的评价指标是否反映真实调度损失？

**依据**：低估一步和高估一步的长度误差可以相同，造成的延迟和无效 Target 费用却可能非常不同。

**最小实验**：保留同一批预测，按长度误差和真实调度损失分别排序，检查模型优劣是否经常反转；同时给 SFT 与 TD 相同的调参预算。

**可能价值**：先建立可信的诊断和 baseline；如果误差与决策损失脱节，再考虑概率预测或效用学习。

**放弃条件**：两种评价基本一致，或简单后处理已解决。它与 R1 高度相关，应先合并调查，不拆成多个“大 idea”。实现难度低到中。

## 8. 下一篇如何接着读

下一篇 **PASTE**。重点只带三个问题过去：

1. 它利用什么结构避免重复计算，与 DSP 的匹配长度预测有何不同？
2. 它的调度是否已经考虑真实工具时间和投机收益，从而覆盖 R1？
3. 提交工具结果依赖哪些状态条件，pattern 命中是否足够？

当前最值得保留的是一个问题，而非方案：**当投机深度预测已经有人做了，我们能否证明一个简单、重要且现有控制目标没有覆盖的决策缺口？**
