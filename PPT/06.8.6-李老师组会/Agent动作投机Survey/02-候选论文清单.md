# A：Agent 动作投机——候选论文清单

更新时间：2026-08-03

## 筛选结果

本轮内部检索覆盖了动作投机、工具调用投机、自投机、动态投机深度、轨迹模式预测、语义验证、流式交互和工作流回滚等关键词。最终保留 10 篇：7 篇为 2026 年论文或 2026 年正式版本，3 篇为 2025 年直接相关工作。

### S 级：建议精讲并制作独立 PPT

#### S1. Speculative Actions: A Lossless Framework for Faster Agentic Systems

- 时间：2025-10 投稿；2026-04 更新 v2；ICLR 2026。
- 论文：https://arxiv.org/abs/2510.04371
- 定位：Agent 动作投机的基础框架，将“预测—验证—提交”从 Token 层推广到动作/API 层。
- 核心机制：快速 Speculator 在权威 Actor 或环境调用尚未完成时预测可能结果，并提前启动下一动作；命中则复用，未命中则丢弃。
- 代表性：定义了本 Survey 的基本问题、术语和无损执行语义。
- 主要结果：最高约 55% 的下一动作预测命中率，最高约 20% 端到端时延下降。
- 代码：https://github.com/naimengye/speculative-action
- 本地材料：LaTeX 源码和已有 8 页汇报 PPT 均完整。

#### S2. Dynamic Speculative Agent Planning

- 时间：2025-09。
- 论文：https://arxiv.org/abs/2509.01920
- 定位：从固定投机步数 k 扩展到动态多步投机，并显式控制延迟—成本权衡。
- 核心机制：Approximation Agent 与 Target Agent 并行；DistilBERT 预测合适的投机深度 k，通过在线 TD/expectile 学习持续更新；失配时取消后续线程。
- 代表性：回答“应当投机多远”，适合作为 Speculative Actions 之后的动态控制路线。
- 主要结果：在保持接近最快固定策略的速度时，总成本最多下降约 30%，无效成本最多下降约 60%。
- 代码：https://github.com/guanyilin428/Dynamic-Speculative-Planning
- 本地材料注意：当前名为 `DYNAMIC SPECULATIVE AGENT PLANNING` 的目录与 PASTE 目录内容逐字相同，并不是真正的 DSP 源码；制作 PPT 时需重新取得 DSP 官方源码或使用 arXiv HTML/PDF。

#### S3. Parallelizing Tool Execution and LLM Generation for Low-Latency Agent Serving（PASTE）

- 时间：2026-03 投稿；2026-06 更新 v3。
- 论文：https://arxiv.org/abs/2603.18897
- 标题变更：早期版本曾使用 “Act While Thinking: Accelerating LLM Agents via Pattern-Aware Speculative Tool Execution”；当前 v3 标题为 “Parallelizing Tool Execution and LLM Generation for Low-Latency Agent Serving”。
- 定位：将动作投机落实为完整 Agent Serving 系统。
- 核心机制：Pattern Analyzer 从历史轨迹提取控制流和数据流模式；Tool Speculation Scheduler 隔离并调度提前执行；LLM–Tool Co-Scheduler 控制返回 LLM 的会话，避免把工具侧收益转化为 GPU 排队。
- 代表性：强调“投机预测正确”并不等于“系统端到端一定更快”，把并发负载和调度纳入研究。
- 主要结果：平均任务完成时间下降 43.5%，观察到的工具延迟降低 1.8 倍。
- 代码：arXiv 页面未给出公开仓库；用户已保存当前版本 LaTeX 源码和全部主要图片。

#### S4. SPORK: Self-Speculative Forking to Accelerate Agentic LLM Inference

- 时间：2026-07。
- 论文：https://arxiv.org/abs/2607.03333
- 定位：无需辅助小模型、历史轨迹或训练，让正在运行的 Actor 自己预测自己的工具调用。
- 核心机制：首 Token 后共享 Prefix KV Cache 创建 forced tool-call probe；用 logprob 置信度控制何时执行工具；预测失败时把共享前缀作为 Token 级草稿复用。
- 代表性：给出“训练免费自投机”路线，并把 Agent 动作投机与 Token 级 speculative decoding 连接起来。
- 主要结果：真实工具任务上 P95 时延下降约 6%–18%，任务准确率与基线相差不超过约 1 个百分点。
- 代码：https://github.com/baihuajun24/spork

#### S5. Speculate While You Reason: Teaching Agents to Predict Their Next Tool Call via Joint Agent–Speculator RL

- 时间：2026-07-28。
- 论文：https://arxiv.org/abs/2607.25816
- 定位：训练一个模型同时承担 Agent 和 Speculator 两种模式，解决外部 Speculator 与目标 Agent 的行为分布不一致。
- 核心机制：从 Agent 自己的 rollout 构造下一工具调用监督；先进行双模式 SFT，再交替进行 Agent 与 Speculator 的 RL 更新，并在模式切换时重置优化器状态。
- 代表性：与 SPORK 形成很好的对照——同样是自投机，一个训练免费，一个通过联合训练主动提高 Hit@1。
- 主要结果：平均 Hit@1 从 44.1 提升到 61.2（Qwen3-4B），从 48.9 提升到 66.3（Qwen3.5-4B），匹配域内任务成功率基本保持。
- 代码：截至本轮检索，arXiv 页面未提供公开代码链接。

### A 级：Survey 对比中重点介绍，暂不制作独立 PPT

#### A1. DualSpec: Accelerating Deep Research Agents via Dual-Process Action Speculation

- 时间：2026-03。
- 论文：https://arxiv.org/abs/2603.07416
- 核心机制：把 Search 视为高不确定性的 System 2 动作，把 Visit 视为低不确定性的 System 1 动作；分别使用小模型带推理和大模型无推理生成草稿，再用语义 Critic 验证。
- 重要性：代表“按动作类型选择投机策略”和“语义验证替代严格匹配”。
- 结果：报告 1.33–3.28 倍端到端加速，准确率与完整推理 Agent 接近。
- 注意：语义接受会改变权威 Agent 的原始轨迹，因此不是严格意义上的无损执行。

#### A2. Speculate with Memory: Lossless Acceleration for LLM Agents

- 时间：2026-07。
- 论文：https://arxiv.org/abs/2607.12236
- 核心机制：为 Speculator 增加对比动作转移表、情景记忆和混淆追踪器；覆盖动作预测、观测预测和链式预测。
- 重要性：代表“从无状态 Speculator 到跨任务积累经验”的路线。
- 结果：动作预测相对准确率提高 19%–39%，重复动作空间中的观测预测最高提高 2.5 倍。
- 代码：截至本轮检索，arXiv 页面未提供公开代码链接。

#### A3. Reducing Latency of LLM Search Agent via Speculation-based Algorithm-System Co-Design（SPAgent）

- 时间：2025-11。
- 论文：https://arxiv.org/abs/2511.20048
- 核心机制：搜索早期使用不验证的激进投机，后期切换为推理与投机并行的验证阶段；配合负载感知的投机选择和短作业优先调度。
- 重要性：代表“分阶段投机”和“算法—系统协同设计”。
- 结果：报告 1.08–1.65 倍端到端加速。
- 注意：早期阶段省略验证，因此不是严格无损框架。

#### A4. Speculative Interaction Agents: Building Real-Time Agents with Asynchronous I/O and Speculative Tool Calling

- 时间：2026-05。
- 论文：https://arxiv.org/abs/2605.13360
- 核心机制：把用户流式输入和工具返回都建模为异步事件；基于不完整用户输入提前发起工具；危险工具等待最终确认；为小模型设计 clock-based SFT。
- 重要性：说明投机窗口不仅来自工具等待，也可以来自“用户尚未说完”和异步环境返回。
- 结果：云端实时模型加速 1.3–1.7 倍但有轻微准确率下降；3B 模型加速 1.6–2.2 倍。

#### A5. Sherlock: Reliable and Efficient Agentic Workflow Execution

- 时间：2025-11。
- 论文：https://arxiv.org/abs/2511.00330
- 核心机制：在验证上游工作流节点的同时，提前运行其下游节点；验证失败时根据依赖关系选择性回滚。
- 重要性：它不预测“下一动作”，但展示了另一类 Agent 投机窗口——隐藏 Verifier 的等待时间。
- 结果：相对非验证基线平均准确率提高 18.3%，相对非投机验证执行最高减少 48.7% 执行时间。
- 注意：属于工作流级 run-ahead speculation，是本 Survey 的边界工作。
