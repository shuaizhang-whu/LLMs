# B．端云协同 Agent：关键词树

## 1. 研究对象

- Device–Cloud / Edge–Cloud Collaborative Agent
- Local SLM + Cloud LLM
- On-device Agent / Edge Agent
- Split Computing / Collaborative Inference
- Agent Router / Coordinator / Escalation Policy

## 2. 协同粒度

- 请求级路由：整条 query 在本地或云端二选一
- 子任务级分解：云端规划，本地并行执行短子任务
- Agent 步级路由：每个 state/action step 动态决定本地或云端
- 模型层切分：embedding、KV cache、decoder、verification 分布式执行
- 安全层分工：本地筛查、云端语义分析、本地确定性执行守卫

## 3. 优化目标

- 任务成功率 / Cloud-only performance recovery
- 端到端延迟、网络抖动、交互响应性
- 云 API 成本、云调用率、token 与通信负载
- 隐私暴露：原始 UI、局部 UI block、用户本地数据、运行时状态
- 可用性：离线、弱网、异构终端
- 可信执行：隔离、远程证明、最小权限

## 4. 方法关键词

- Query routing / Step-level routing / Cascading
- Confidence / Entropy / Device–cloud agreement
- Imitation learning + cost-aware reinforcement learning
- Task decomposition + local parallel execution
- Layout-aware UI partition / selective disclosure
- Prefix caching / prompt reconstruction / speculative decoding
- Endpoint-authenticated KV cache / encrypted split inference
- Confidential VM / TEE / Arm CCA
- Defense funnel / edge sentinel / cloud planner / deterministic guard

## 5. 评测指标

- Success Rate、Cloud-only recovery ratio
- Cloud invocation ratio、API cost、token cost
- End-to-end latency、per-step routing overhead
- UI exposure reduction / transmitted payload
- Privacy/security attack success rate
- Runtime overhead、energy、memory footprint

## 6. 检索式

- `("device-cloud" OR "edge-cloud") AND (LLM agent OR agentic)`
- `on-device agent cloud collaboration`
- `step-level routing LLM agent`
- `local small model cloud large model agent`
- `mobile GUI agent privacy cloud local`
- `split compute browser agent security`
- `confidential agent execution edge device`

## 7. 与 A/C/D 的接口

- A→B：本地轻量模型可作为 Speculator，云端强模型可作为 Actor/Verifier；Agent-X、Cassandra 展示端侧投机加速。
- B→C：GUI 是端云协同最自然的应用场景；CORE 将本地 UI 过滤与云端决策组合。
- B→D：路由策略不仅决定成本，也决定隐私和错误暴露；AgenTEE 与 Cognitive Firewall 将协同扩展到可信执行。
