# B．端云协同 Agent：候选论文清单

筛选原则：以用户提供的 CORE、Hera 为种子；优先 2026；必须能回答“谁在本地、谁在云端、何时切换、传什么、如何评估”中的至少一个问题。S=主讲，A=补充，X=桥接专章。

| 级别 | 论文 | 年份 | 角色 | 入选理由 | 建议页数 |
|---|---|---:|---|---|---:|
| S | [Hera: Learning Long-Horizon Coordination for Device–Cloud Collaborative LLM Agents](https://arxiv.org/abs/2605.24598) | 2026 | 步级动态路由 | B 的最直接 Agent baseline；IL 冷启动 + cost-aware RL；以成功率、云调用和延迟共同评估 | 6 |
| S/X | [CORE: Reducing UI Exposure in Mobile Agents via Collaboration Between Cloud and Local LLMs](https://arxiv.org/abs/2510.15455) | 2025 | UI 选择性披露 | 用户种子；本地负责 block 排序、云端负责精细决策；同时连接 B、C 与隐私可靠性 | 6 |
| S | [Minions: Cost-efficient Collaboration Between On-device and Cloud Language Models](https://arxiv.org/abs/2502.15964) | 2025 | 协作范式基础 | 云端分解、端侧并行执行；从 request routing 过渡到可组合协作协议 | 4 |
| S/X | [Agent-X: Full Pipeline Acceleration of On-device AI Agents](https://arxiv.org/abs/2605.10380) | 2026 | 端侧 Agent 加速 | PromptWeaver + LLM-free speculative decoding；连接 A 与 B | 4 |
| S/X | [Mobile-Agent-v3.5: Multi-platform Fundamental GUI Agents](https://arxiv.org/abs/2602.16855) | 2026 | 云边模型谱系 | 2B–235B 多尺寸、跨桌面/移动/浏览器，明确支持 cloud-edge collaboration | 4 |
| A/X | [Efficient and Privacy Aware Edge Cloud Collaborative Inference for Large Language Models](https://arxiv.org/abs/2607.13093) | 2026 | 模型层切分 | endpoint-authenticated KV、端侧投机、云端验证；用于说明“协同不止路由” | 3 |
| A/X | [AgenTEE: Confidential LLM Agent Execution on Edge Devices](https://arxiv.org/abs/2604.18231) | 2026 | 可信端侧执行 | 多 cVM + 远程证明，<5.15% overhead；连接 B 与 D/安全 | 3 |
| S/X | [The Cognitive Firewall: Securing Browser Based AI Agents Against Indirect Prompt Injection Via Hybrid Edge Cloud Defense](https://arxiv.org/abs/2603.23791) | 2026 | 安全型端云分工 | 本地 Sentinel + 云端 Deep Planner + 本地 Guard；同时覆盖 B、C、D | 5 |
| A | [Large Language Models over Networks: Collaborative Intelligence under Resource Constraints](https://arxiv.org/abs/2605.08626) | 2026 | 综述/总览 | 用于 B 开篇的 vertical device-cloud 与 horizontal collaboration 二维分类，不单独深讲 | 1–2 |

## 最终主讲组合

1. Minions：先解释为什么不应只做“本地/云端二选一”。
2. Hera：将协同粒度推进到长轨迹的每一步。
3. CORE：把路由问题落到移动 GUI 的隐私暴露。
4. Agent-X：说明协同之前，本地 Agent 本身仍需全流水线加速。
5. Mobile-Agent-v3.5：给出跨平台、跨尺寸模型的云边部署载体。
6. Cognitive Firewall：把性能协同推进到安全协同。

其余三篇用于对比或桥接，不把 B 扩展成泛边缘推理综述。
