# C．GUI Agent 执行：统一对比表

| 方法 | 平台 | 观察 | 动作 | 验证时机 | 关键机制 | 关键结果 | 局限 |
|---|---|---|---|---|---|---|---|
| OSWorld | Ubuntu/Windows/macOS | screenshot + a11y tree | GUI + keyboard/CLI | 任务结束，脚本式 | 可复现初始状态 + 134 类 evaluator | 369 tasks；人类 72.36%，当时最佳模型 12.24% | 是环境/benchmark，不是新执行策略；脚本真值可能漏掉替代路径 |
| UFO² | Windows，20+ apps | UIA + vision + app state | GUI + native/API | 轻量 control-state check；safeguard | HostAgent/AppAgent、统一 action layer、speculative multi-action、PiP | 对比专用 CUA 总体提升超过 10%（论文报告） | Windows/应用适配成本；强依赖系统接口 |
| CORE | Android/mobile | XML hierarchy/block | element action | 多轮候选累积 | layout-aware partition + co-plan/co-decision | UI exposure 最多减 55.6% | 纯视觉/无 XML 页面适用性有限 |
| Mobile-Agent-v3.5 | desktop/mobile/browser | multimodal unified | GUI + Tool/MCP | 训练/奖励闭环 | GUI-Owl-1.5 多尺寸；hybrid data flywheel；MRPO | OSWorld 56.5、AndroidWorld 71.6、WebArena 48.4 | 训练体系很重；系统性失败恢复仍需外部模块 |
| GUI-Critic-R1 | mobile/web | screenshot + instruction/history + candidate action | 给 critique/suggestion，不直接执行 | 执行前 | reasoning bootstrapping + RFT + S-GRPO | AndroidWorld baseline success 22.4%→27.6% | 每步多一次 critic；训练使用 8×A100；可能过度阻止 |
| VeriGUI | Android/mobile | current state + history + expected effect | action + expectation + recovery | 每步执行后反馈到下一步 | TVAE、Robust SFT、GRPO asymmetric reward | 3B/7B RSR 51.1%/52.5%；7B Sim-TSR 23.5% | 伪在线/失败注入与真实噪声仍有差异；训练成本高 |
| VAGEN | OSWorld/AndroidWorld | trajectory screenshots + environment probes | shell/Python/GUI read/probe | 任务结束/奖励 | progressive verification，surface→latent、cheap→expensive | OSWorld human-ground-truth Acc 92.9/93.4%；RL SR 34.3% | Outcome-level；主动 probing 需权限和沙箱 |
| IRA | Ubuntu，10 app categories | final screenshots + system/app/artifact state | GUI/system/app verification tools | 任务结束/奖励 | propose completion conditions → verify evidence | GUI-RewardBench 86.9% Acc；RL OSWorld SR 34.0% | token/交互成本高；最新结果尚需复核 |

## 统一执行闭环

`观察/定位 → 计划 → 候选动作 → 执行前 critic → 执行动作 → 状态效果验证 → 自纠错/回滚 → 完成条件验证`

OSWorld 提供环境；UFO²/GUI-Owl 提供 Actor；GUI-Critic-R1 提供 pre-check；VeriGUI 提供 step-level effect check；VAGEN/IRA 提供 outcome verifier。它们不是替代关系，而是可组合的系统层次。
