# C．GUI Agent 执行：候选论文清单

筛选原则：以用户目录中的 OSWorld、UFO²、CORE 为种子；重点是“真实执行、系统集成、动作验证和恢复”，不把纯视觉 grounding 模型堆成榜单。S=主讲，X=桥接。

## 最终主讲组合

- OSWorld：为什么 GUI Agent 必须在真实可执行环境中评估。
- UFO²：如何把“会看截图的模型”升级成 OS 级执行系统。
- CORE / Mobile-Agent-v3.5：如何跨本地、云端和多平台部署。
- GUI-Critic-R1 → VeriGUI → VAGEN/IRA：按执行前、执行中、执行后构成完整可靠性闭环。

这条顺序让 C 成为一个执行系统故事，而不是每篇论文独立介绍。
