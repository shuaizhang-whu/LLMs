# C．GUI Agent 执行：关键词树

## 1. 环境与平台

- Web / Browser Agent
- Mobile / Android / iOS Agent
- Desktop / OS Agent / Computer-Using Agent (CUA)
- Cross-platform GUI Agent
- Real computer environment / sandbox / virtual desktop

## 2. Agent 执行循环

- Observation：screenshot、DOM、accessibility tree、UIA、XML hierarchy
- Grounding：element、coordinate、control、region、text
- Planning：task decomposition、subgoal、multi-action plan
- Action：click、type、scroll、keyboard、shell、API、MCP
- Effect verification：expected state vs observed state
- Recovery：retry、re-ground、rollback、alternative action
- Completion verification：hidden state、artifact、system setting、application state

## 3. 系统实现

- GUI-only vs API-only vs hybrid GUI–API
- HostAgent / AppAgent / multi-agent orchestration
- Native OS integration / Windows UI Automation
- Isolated execution / Picture-in-Picture / remote desktop loopback
- Speculative multi-action / action chunking / dynamic commitment
- Memory、documentation、execution trace retrieval

## 4. 可靠性机制

- Pre-operative critic：执行前判断动作正确性与潜在后果
- Post-action verification：验证动作是否生效
- Action-effect expectation：预测状态转移并比对
- Interactive verifier / reward agent：主动读取系统、应用、文件证据
- Read-only verification / sandbox / minimum permission

## 5. Benchmark 与指标

- OSWorld、AndroidWorld、WebArena、ScreenSpotPro
- task success / progress / step success / grounding rate
- loop rate / recovery success / average step overhead
- verifier accuracy / F1 / human agreement
- end-to-end latency / LLM calls / action steps

## 6. 检索式

- `GUI agent action execution verification`
- `computer-using agent robust execution self-correction`
- `desktop agent OS integration GUI API`
- `mobile agent pre-operative critic`
- `GUI task evaluation environment-state verification`
- `speculative multi-action GUI agent`

## 7. 与 A/B/D 的接口

- A→C：UFO² 的 speculative multi-action 将多步 GUI 动作一次生成并轻量验证；A3 将 action prefix acceptance 形式化。
- B→C：CORE、Mobile-Agent-v3.5 把本地感知/模型与云端推理组合。
- C→D：GUI-Critic-R1、VeriGUI、VAGEN、IRA 将可靠性插入执行前、执行中和执行后。
