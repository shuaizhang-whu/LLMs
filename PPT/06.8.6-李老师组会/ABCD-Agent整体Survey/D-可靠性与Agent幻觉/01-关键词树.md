# D．可靠性与 Agent 幻觉：关键词树

## 1. 定义边界

- Agent hallucination：动作/思考/声明不被任务、历史、观察或证据支持
- Tool hallucination：工具类型、调用时机、格式、参数内容失真
- General agent failure：还包括环境错误、格式错误、超时、资源限制；不全是幻觉
- Security compromise：prompt injection/权限越界可能诱发错误动作，但与自然幻觉不同

## 2. 粒度

- Response-level：最终答案是否有事实错误
- Action-level：下一动作是否忠实于当前上下文
- Step-level：Thought–Action–Observation 中哪一步首次偏离
- Trajectory-level：错误如何传播、是否多类型共存
- System-level：Agent、工具、环境、权限和 judge 的联合可靠性

## 3. 类型

- Planning / memory / reflection / retrieval / reasoning
- Tool selection / timing / format / content
- Factual / referential / logical / procedural / scope
- Observation mismatch / unsupported completion claim / fabricated UI element
- Judge hallucination / false positive / false negative

## 4. 研究任务

- Elicitation：构造 no-tool、distractor、unexpected transition、unachievable goal
- Detection：判断是否幻觉
- Attribution：定位 root-cause step 并解释原因
- Propagation：测量错误从参数/动作传播到最终结果的概率
- Mitigation：abstain、ask user、change tool、verify、retry、rollback、block
- Auditing：对完整轨迹与角色边界进行事后审计

## 5. 方法

- Taxonomy-grounded LLM judge / multi-judge ensemble
- Rule + semantic evaluator
- Contextual snapshot / controlled error injection
- Pre-operative critic / action-effect verifier
- Reliability alignment：SFT/DPO + indecisive actions
- Runtime interceptor / guard / sandbox
- Local lightweight verifier / cloud escalation

## 6. 评价指标

- Hallucination Rate、Tool Hallucination Rate
- step localization accuracy / all-correct / causal explanation quality
- judge–human Cohen’s κ / precision / recall / F1
- rejection / recovery / propagation probability
- Reliable Pass Rate / Benefit–Cost Utility
- task success after mitigation、extra calls、latency、over-refusal

## 7. 与 A/B/C 的接口

- A→D：投机执行只有在验证不改变 Actor 语义时才“lossless”；接受率之外还需副作用与回滚安全。
- B→D：本地 verifier/guard 可减少隐私暴露与云成本，云端强模型处理高风险语义判断。
- C→D：GUI 错误具有不可逆副作用；pre-check、effect check、outcome verifier 分别覆盖风险闭环。
